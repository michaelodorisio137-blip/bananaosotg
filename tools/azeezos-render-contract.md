# RG DS renderer contract
Physical panel: 640x480. Logical low-resolution canvas: 320x240, enlarged exactly 2x. Native 480p: 640x480 at 1:1. Original LCD pixels remain centered, untouched by fractional interpolation. DS native 256x192 starts at (32,24) logical / (64,48) physical. GBA native 240x160 starts at (40,40) logical / (80,80) physical. A 3D target is a canvas dimension, not a multiplier of the original LCD. No overscan masking that removes valid output. Expose true scene/background where source permits; no fictitious scene or forced stretching. Preserve original timing, sprite coordinates, touch coordinates, and existing save compatibility. Unsupported content/resolutions (e.g. interlaced PS1 and original 16:9 PSP) require explicit per-core handling, not arbitrary cropping. 
Audit: GBA GLES exterior geometry excludes 153600 native pixels per 640x480 frame (50% of target), already drawn by native compositor; actual timing gain requires hardware profiling. DS blank/no-layer exterior spans use identical color fill, and legacy game-specific 3x/4x requests map to 480p in expanded mode. Packaged N64/PS1 selections no longer take the generic unknown-core path. N64 retains triple buffering; reflection uses the producer tap without GPU scanout synchronization. No claim of hardware full speed. 
Clean builds compile all listed open-source emulators from a common commit without reusing previously compiled artifacts. Proprietary DraStic and external downloadable cores are not rebuildable from our source; preserve those. Each build group retains its provenance and checksum manifest. Do not delete rollback OTA releases.
