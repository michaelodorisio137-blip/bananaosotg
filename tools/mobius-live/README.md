Experimental libretro emulator, not a standalone PortMaster executable. Load the .so in a compatible ARM64 RetroArch installation, then load an original matching Drome Racers USA or Hot Wheels Stunt Track Challenge USA/Europe ROM. Select+L+R toggles a provisional live geometry overlay. Default is normal GBA emulation. The original rasterizer always runs; no guest instructions are skipped. The flat and affine textured triangles are inferred from binary analysis, and texture bank layout, UV scaling, layer ordering, viewport orientation and clipping are unverified in real gameplay. Screen texture and point commands are not converted. N64-style triangular three-point interpolation is applied only to overlay textures. No firmware files are overwritten. This uses Ubuntu ARM64 glibc; target ABI and GLES3 runtime must be verified on RG DS. No game ROMs included.
